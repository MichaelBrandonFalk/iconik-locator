Iconik Locator

Download Iconik Locator for Windows, Linux Mint, or Mac to turn Iconik links into usable storage paths, including AWS CLI-ready s3:// URLs.

Download v7.0.11

Windows 10 / 11 · 64-bit ZIP Linux Mint 21 / 22 · 64-bit Installer Mac · Apple Silicon ZIP

Windows and Linux downloads are for Intel/AMD 64-bit computers. The Mac download is for M1 and newer. Python is included; no separate Python installation is needed.

Linux portable archive · GitHub repo and more options

Windows

  1. Download the Windows ZIP. Right-click it and choose Extract All.
  2. Open the extracted folder and double-click Iconik Locator 7.0.11.exe.
  3. Keep the _internal folder beside the executable.

Linux Mint

  1. Download the Linux Mint installer (.deb).
  2. Double-click the file to open Package Installer, then click Install Package.
  3. Open Iconik Locator from the Mint application menu.

For the portable archive, extract it and open iconik-locator-7.0.11. If needed, allow execution in file Properties > Permissions.

Mac

  1. Download the Mac ZIP and double-click it to extract it.
  2. Move Iconik Locator 7.0.11_arm64.app to Applications and open it.
  3. If macOS blocks it, open System Settings > Privacy & Security, then choose Open Anyway for Iconik Locator.

Use The App

  1. Enter your Iconik App-ID and Auth-Token.
  2. Leave output set to S3 for AWS CLI-ready URLs.
  3. Paste an Iconik asset link, share link, asset UUID, collection link, or s3:// URI.
  4. Click Locate.
  5. Use Copy S3 Only when you only need the final s3:// paths.
With saving enabled, credentials are stored on your computer in Windows Credential Manager, the Linux login keyring, or macOS Keychain. On Linux Mint, unlock your login keyring in Passwords and Keys if prompted. Tokens are never uploaded to GitHub.

Bulk Lookup

  1. Open the Bulk Lookup tab.
  2. Paste one Iconik URL, share URL, UUID, or s3:// URI per line.
  3. For CSV or Excel upload, use a column header named iconik_url.
  4. Click Run Bulk Lookup.
  5. Export results as CSV or XLSX, or copy only the S3 outputs.

Iconik Credentials

Ask your Iconik admin for an App-ID and Auth-Token with asset/file lookup access.

Iconik API setup instructions

Most users should keep the Iconik host set to https://app.iconik.io. Change it only if your organization uses a different Iconik host.

Supported Inputs
