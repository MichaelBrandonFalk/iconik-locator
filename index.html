Iconik Locator

Download the local Mac app to turn Iconik links into usable storage paths, including AWS CLI-ready s3:// URLs.

Download For Mac

Download Mac App v7.0.8 GitHub Repo

This build is for Apple Silicon Macs: M1, M2, M3, and newer. CLI and build options are available in the GitHub repo.

Install And Open

  1. Download Iconik_Locator_App_v7_0_8_arm64.zip.
  2. Double-click the zip file to extract it.
  3. Open Iconik Locator 7.0.8_arm64.app.
  4. If macOS blocks it, open System Settings > Privacy & Security, then choose Open Anyway for Iconik Locator.

Use The App

  1. Enter your Iconik App-ID and Auth-Token.
  2. Leave output set to S3 for AWS CLI-ready URLs.
  3. Paste an Iconik asset link, share link, asset UUID, collection link, or s3:// URI.
  4. Click Locate.
  5. Use Copy S3 Only when you only need the final s3:// paths.
The app saves credentials and settings locally when the save option is enabled, so users do not need to paste them every time.

Bulk Lookup

  1. Open the Bulk Lookup tab.
  2. Paste one Iconik URL, share URL, UUID, or s3:// URI per line.
  3. For CSV or Excel upload, use a column header named iconik_url.
  4. Click Run Bulk Lookup.
  5. Export results as CSV or XLSX, or copy only the S3 outputs.

Iconik Credentials

Ask your Iconik admin for an App-ID and Auth-Token with asset/file lookup access.

Iconik API setup instructions

Most users should keep the Iconik host set to https://app.iconik.io. Change it only if your organization uses a different Iconik host.

Supported Inputs

  • Iconik asset links
  • Iconik share links
  • Iconik asset UUIDs
  • Iconik collection links
  • s3://bucket/path/file.mov reverse lookups
