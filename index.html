Iconik Locator

Paste an Iconik asset link, share link, asset UUID, collection link, or S3 URI. Get usable storage paths or reverse-map an S3 path back to Iconik.

Browser Tool

Credentials stay in this browser session. The request is sent directly from your browser to Iconik.

Ask your Iconik admin for an App-ID and Auth-Token with asset/file lookup access. Need these?

Default behavior: if the Iconik URL represents multiple assets, the tool lists each asset and its output.
