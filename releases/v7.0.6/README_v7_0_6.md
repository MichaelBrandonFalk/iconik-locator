# Iconik Storage Locator v7.0.6

This release removes the browser lookup workflow from the public GitHub Pages experience and makes the page a clear local Mac app download and setup guide.

## Changes

* Public page now focuses on downloading, opening, and using the local macOS app.
* Browser lookup fields and browser bulk lookup controls are no longer shown.
* Page explains that Iconik can block direct GitHub Pages API requests and that the local Mac app is the supported path.
* Download links and app artifact names are versioned as `v7.0.6`.
