# Iconik Storage Locator v7.0.1

Refines the UI around multi-asset Iconik links.

## Changes

* Share links now default to resolving every represented asset (`ALL`).
* Desktop app shows the default behavior directly and moves share/file multi behavior into Advanced Settings.
* Browser tool matches the desktop UI and clears old saved multi-asset defaults from prior sessions.
* Results now explicitly state when one Iconik URL resolves to multiple assets.

## Artifacts

* `Iconik_Locator_App_arm64.zip`
* `iconik_locator_arm64.zip`
* `checksums.txt`

Intel artifacts are produced by the same build script when an x86_64/Rosetta Python is available.
