# Iconik Storage Locator v7.0.2

Clarifies Iconik credential requirements.

## Changes

* Renamed the credential section to Iconik API Access.
* Hid Iconik host in Advanced Settings and kept the default at `https://app.iconik.io`.
* Added a `Need these?` help link to Iconik's official API setup instructions.
* Documented that App-ID and Auth-Token are required for real lookups.

## Artifacts

* `Iconik_Locator_App_arm64.zip`
* `iconik_locator_arm64.zip`
* `checksums.txt`

Intel artifacts are produced by the same build script when an x86_64/Rosetta Python is available.
