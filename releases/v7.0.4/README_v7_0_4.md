# Iconik Storage Locator v7.0.4

Adds a quick API access test and simplifies public downloads.

## Changes

* Added `Test API Access` to the browser tool and desktop app.
* The API test verifies that Iconik accepts the entered App-ID/Auth-Token and that the token can access the files/storages API used by this locator.
* Kept the public download card focused on the macOS app.
* Replaced the direct CLI download button with a GitHub repo link for CLI and build options.

## Artifacts

* `Iconik_Locator_App_arm64.zip`
* `iconik_locator_arm64.zip`
* `checksums.txt`

Intel artifacts are produced by the same build script when an x86_64/Rosetta Python is available.
