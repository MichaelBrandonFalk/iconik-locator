# Iconik Storage Locator v7.0.9

This release fixes the Single Lookup button row in the macOS app and includes the GitHub Pages hero `s3://` styling fix.

## Changes

* Single Lookup buttons now use a fixed-height action row so they remain visible when the app window is short.
* Only the result output area expands vertically in the Single Lookup tab.
* Header inline `s3://` text on the website no longer appears as a pale code badge.
* Download links and app artifact names are versioned as `v7.0.9`.
